# Місія №3: Інформаційний Сховок (Data Stash)

Агенте, твоя місія — модифікувати файл `memory.asm`.

Ти маєш не лише обчислити суму (100 + 42), але й виконати операцію "сховку":

* Заховати результат (142) у безпечну комірку в пам'яті (`result`).
* Записати точні координати (адресу) цього сховку в **EBX** для звіту.

## Ваше Завдання

### 1. Модифікуй memory.asm

* Відкрий файл `memory.asm` у редакторі.
* Знайди коментарі з `???`.
* Тобі потрібно заповнити **ДВІ** пропущені інструкції:

**ЗАВДАННЯ (ЧАСТИНА 2):**

* **Мета:** Зберегти значення з регістра **EAX** (яке дорівнює 142) всередину комірки пам'яті `result`.
* **Підказка:** Нам потрібні `[ ]` дужки, щоб вказати, що ми пишемо всередину пам'яті.

**ЗАВДАННЯ (ЧАСТИНА 3):**

* **Мета:** Завантажити адресу комірки `result` (а не її вміст!) у регістр **EBX**.
* **Підказка:** Нам не потрібні `[ ]` дужки, бо ми беремо саму "мітку".

## Інструкція по виконанню

### Крок 1: Компіляція

У терміналі виконай:

```bash
make
```

Це створить виконуваний файл `memory`.

### Крок 2: Підготовка до Діагностики (GDB)

Запусти відлагоджувач:

```bash
gdb ./memory
```

Встанови точку зупину (breakpoint) на початку:

```gdb
(gdb) b _start
```

Запусти програму:

```gdb
(gdb) run
```

### Крок 3: Виконання

Програма зупиниться на `_start`. Нам потрібно виконати всі наші інструкції.

Виконуй команду `ni` (next instruction) крок за кроком, поки не дійдеш до інструкції `mov eax, 1`. Це початок секції виходу, і це означає, що всі наші обчислення та збереження завершені.

Програма зупинена. Час перевірки.

## Перевірка Сховку (GDB)

Ми проводимо два тести.

### Тест 1: Перевірка Адреси (Регістр EBX)

Спочатку дізнаємося у `gdb`, яку адресу він очікує для `result`.

```gdb
(gdb) p &result
```

GDB покаже щось на кшталт: `$1 = (int *) 0x804a008` (ваша адреса може відрізнятися).

Тепер перевіримо, що лежить у **EBX**:

```gdb
(gdb) info registers ebx
```

**ОЧІКУВАНИЙ РЕЗУЛЬТАТ:**  
Значення `ebx` має **точно збігатися** з адресою, яку показав `p &result` (напр., `ebx 0x804a008 134520840`).  
Це доводить, що ви правильно завантажили адресу.

### Тест 2: Перевірка Вмісту (Пам'ять [result])

Ми знаємо адресу (вона в **EBX**, напр. `0x804a008`). Тепер "зазирнемо" всередину цієї комірки пам'яті.

Використовуйте команду `x` (examine) з адресою з Тесту 1.  
(Прапорець `/d` означає "показати як десяткове (decimal) число")

```gdb
(gdb) x /d 0x804a008
```

_(Замініть `0x804a008` на вашу реальну адресу з Тесту 1)_

**ОЧІКУВАНИЙ РЕЗУЛЬТАТ:**  
GDB має показати вміст сховку:

```
0x804a008 <result>:	142
```

## Звіт

**Якщо обидва тести пройдені, місія виконана.**

Для виходу з `gdb`:

```gdb
(gdb) quit
```

**Для звіту** зроби скріншоти свого термінала, де чітко видно:

1. Результат Тесту 1 (збіг `p &result` та `info registers ebx`).
2. Результат Тесту 2 (команда `x /d ...` та її вивід, що показує 142).
