# МІСІЯ №04: БЕЗПЕЧНИЙ ПРОТОКОЛ (HELLO CARGO)

Агенте, час перейти на вищий рівень автоматизації. Твій термінал переведено на Rust.

## ЯК ВИКОНАТИ МІСІЮ:

1. **Створи проект:**
   ```bash
   cargo new mission_04 && cd mission_04
   ```

2. **Відредагуй src/main.rs:**
   Встав повідомлення зі своїм прізвищем.

3. **Перевір маніфест:**
   Відкрий `Cargo.toml` та переконайся, що ім'я проекту `mission_04`.

4. **Запусти діагностику:**
   ```bash
   cargo run
   ```

5. **Згенеруй бойовий бінарний файл:**
   ```bash
   cargo build --release
   ```

## ДОКАЗИ ДЛЯ АРХІТЕКТОРА:

* Скріншот термінала з результатом `cargo run`.
* Звіт із порівнянням розмірів файлів у папках `debug` та `release`.

Майбутнє — за безпечним кодом. Кінець зв'язку.
