# Місія №1: Активація Термінала (Hello, World!)

Агенте, вітаємо у системі. Твоя перша місія — активувати термінал.

## Ваше Завдання

### 1. Ознайомся з кодом

* Відкрий файл `hello.asm` у редакторі.
* Вивчи структуру програми:
  - **section .data** — секція даних (тут зберігається повідомлення)
  - **section .text** — секція коду (тут виконується програма)
  - **_start** — точка входу програми

### 2. Скомпілюй програму

У терміналі виконай:

```bash
nasm -f elf32 hello.asm -o hello.o
ld -m elf_i386 hello.o -o hello
```

Або використай Makefile:

```bash
make hello
```

### 3. Запусти програму

```bash
./hello
```

**Очікуваний результат:**

```
Hello, world!
```

## Що Відбувається?

Програма виконує два системні виклики:

1. **sys_write (номер 4)** — виводить текст на екран
   - EAX = 4 (номер системного виклику)
   - EBX = 1 (stdout)
   - ECX = адреса повідомлення
   - EDX = довжина повідомлення

2. **sys_exit (номер 1)** — завершує програму
   - EAX = 1 (номер системного виклику)
   - EBX = 0 (код завершення - успіх)
