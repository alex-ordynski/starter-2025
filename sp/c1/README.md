**Тема:** **Типи даних та логіка зберігання в Rust.**

**Мета:** Практичне освоєння всіх базових типів даних через виправлення помилок у готовому коді.

**Порядок дій:**

1.  Зайти у свій Codespace.
    
2.  Перейти в папку проекту: cd mission\_05.
    
3.  Відкрити файл src/main.rs.
    
4.  Виконувати завдання по черзі (від №1 до №8).
    
5.  Кожне виправлення перевіряти командою cargo check.
    
6.  Фінальний результат зафіксувати командою cargo run.

Цей вузол містить пошкоджені дані. Твоя мета — відновити цілісність типів.

4.  **Звіт:** Скопіюй фінальний вивід термінала у свій звіт.
