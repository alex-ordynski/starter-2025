# Ласкаво просимо до Гоґвортсу!

Цей репозиторій містить усе необхідне для виконання завдань.

## Що в цьому репозиторії?

* **Середовище Codespaces:** Повністю налаштоване середовище для розробки, яке працює у вашому браузері.
* **Інструменти:** Вже встановлено **Rust**, **SQLite** та **NASM**.
* **База даних:** Файл `hogwarts.db` створюється автоматично. Він містить таблиці для Лабораторної роботи №7.

## Як почати?

1.  Натисніть зелену кнопку **`< > Code`** вгорі сторінки.
2.  Перейдіть на вкладку **"Codespaces"**.
3.  Натисніть **"Create codespace on main"**, щоб запустити ваше робоче середовище.

## Лабораторна робота № 7 ⚡️

**Тема:** Нормалізація: Приведення заданих неструктурованих "брудних" таблиць до нормальних форм (1НФ, 2НФ, 3НФ).

### Мета

- Глибоко засвоїти концепції надмірності даних та аномалій (вставки, оновлення, видалення).
- Опанувати фундаментальні правила Першої (1НФ), Другої (2НФ) та Третьої (3НФ) нормальних форм на різних типах порушень.
- Навчитися практично декомпозувати (розділяти) таблиці, зберігаючи логічні зв'язки через первинні (PK) та зовнішні (FK) ключі.
- Відпрацювати навички перенесення даних зі старих таблиць у нові нормалізовані структури.

### Завдання

Виконати 6 практичних завдань (по 2 на кожну нормальну форму) для очищення архівів Міністерства Магії. Спроєктувати правильні таблиці та продемонструвати їхнє наповнення.

| № | Таблиця | Нормальна форма | Проблема |
|---|---------|-----------------|----------|
| 1.1 | `dirty_potions` | 1НФ | Списки в одній комірці |
| 1.2 | `dirty_student_pets` | 1НФ | Повторювані колонки |
| 2.1 | `dirty_grades` | 2НФ | Часткова залежність |
| 2.2 | `dirty_quidditch_gear` | 2НФ | Часткова залежність |
| 3.1 | `dirty_ministry_registry` | 3НФ | Транзитивна залежність |
| 3.2 | `dirty_mungo_patients` | 3НФ | Транзитивна залежність |

### Опис "брудних" таблиць

#### Завдання 1.1 — `dirty_potions` (1НФ: списки в комірці)

Таблиця зберігає інгредієнти зілля у вигляді одного рядка з комами — порушення атомарності.

#### Завдання 1.2 — `dirty_student_pets` (1НФ: повторювані колонки)

Таблиця має колонки `pet_1`, `pet_2`, `pet_3` замість окремих рядків — повторювані групи атрибутів.

#### Завдання 2.1 — `dirty_grades` (2НФ: часткова залежність)

Складений PK `(student_id, course_id)`, але `course_name` та `professor` залежать лише від `course_id` — часткова залежність.

#### Завдання 2.2 — `dirty_quidditch_gear` (2НФ: часткова залежність)

Складений PK `(player_id, broom_model_id)`, але `manufacturer` та `max_speed` залежать лише від `broom_model_id`.

#### Завдання 3.1 — `dirty_ministry_registry` (3НФ: транзитивна залежність)

`city_name` та `country_name` залежать від `address_code`, а не від `wizard_id` — транзитивна залежність.

#### Завдання 3.2 — `dirty_mungo_patients` (3НФ: транзитивна залежність)

`ward_name` та `head_healer` залежать від `ward_id`, а не від `patient_id`.
