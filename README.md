## Мета

- Зрозуміти різницю між реляційними таблицями та колекціями JSON-документів.

- Навчитися додавати (`insert`), оновлювати (`update`) та видаляти (`delete`) документи.

## 📘 Теоретичний словник-перекладач (SQL -> MongoDB)

Уявіть, що ми зняли жорсткі корсети таблиць. MongoDB — це свобода! Дані зберігаються у форматі BSON (схоже на JSON).

- Таблиця (Table) -> Колекція (Collection)
- Рядок (Row) -> Документ (Document)
- Стовпець (Column) -> Поле (Field)

### Базові заклинання

- `SELECT * FROM creatures` ➡️ `db.creatures.find()`
- `SELECT name, species FROM creatures` ➡️ `db.creatures.find({}, { name: 1, species: 1 })`
- `WHERE danger_level = 5` ➡️ `db.creatures.find({ danger_level: 5 })`
- `WHERE danger_level > 3` ➡️ `db.creatures.find({ danger_level: { $gt: 3 } })`
- `ORDER BY sightings DESC` ➡️ `db.creatures.find().sort({ sightings: -1 })`

### Крок 1: Базовий пошук та сортування (`find`, `sort`, `limit`) 🔍

1. Знайдіть трьох найнебезпечніших істот (`danger_level` дорівнює `5`).
   - Команда: `db.creatures.find({ danger_level: 5 }).limit(3)`
2. Виведіть усіх істот виду `"Niffler"`, відсортованих за кількістю зустрічей (`sightings`) за спаданням.
   - Підказка: використайте `.sort({ sightings: -1 })`. Зробіть скріншот результату.

### Крок 2: Логічні оператори (аналог `AND`, `OR`, `IN`) ⚖️

У MongoDB є спеціальні оператори з префіксом `$`.

1. **Аналог `AND` (неявний):** знайдіть істот, які є хижаками (`"attributes.diet": "Carnivore"`) **і** мають статус `"Missing"`.
   - Підказка: `db.creatures.find({ "attributes.diet": "Carnivore", status: "Missing" })`
2. **Аналог `OR`:** знайдіть істот, які належать до виду `"Dragon"` **або** `"Thunderbird"`.
   - Підказка: `db.creatures.find({ $or: [{ species: "Dragon" }, { species: "Thunderbird" }] })`
3. **Аналог `IN`:** виконайте те саме завдання коротше, використовуючи оператор `$in` для поля `species`.

### Крок 3: Робота з масивами (сила NoSQL) 🌳

У SQL для масиву середовищ існування (`habitats`) довелося б робити окрему таблицю. Тут це просто список `["Hogwarts", "Alps"]`.

Знайдіть усіх істот, у яких у масиві `habitats` є локація `"Hogwarts"`.

- Команда: `db.creatures.find({ habitats: "Hogwarts" })`

### Крок 4: Модифікація даних (`INSERT`, `UPDATE`, `DELETE`) 🪄

1. **INSERT:** додайте нового звіра (`insertOne`). Задайте:
   - `_id: 1000`
   - `name: "Frank"`
   - `species: "Thunderbird"`
   - `danger_level: 4`
2. **UPDATE:** знайдіть Ніфлера Тедді (`_id: 996`). Оновіть його поле `sightings` (встановіть нове значення `105`) за допомогою оператора `$set`.
   - Команда: `db.creatures.updateOne({ _id: 996 }, { $set: { sightings: 105 } })`
3. **DELETE:** видаліть запис про дракона Норберта (`_id: 998`), оскільки Чарлі Візлі забрав його в Румунію назавжди.
   - Використайте `deleteOne`.

### Крок 5: Індивідуальне завдання (екзамен магозоолога) 📜

Розрахуйте свій варіант: `V = N % 4` (`N` — номер у списку журналу). Напишіть Mongo-запит.

- **Варіант 0:** напишіть запит `find`, щоб знайти всіх істот, чий рівень магічної сили (`"attributes.magic_power_level"`) більший за `80` (`$gt`) і які зараз знаходяться у валізі (`status: "In Suitcase"`).
- **Варіант 1:** напишіть запит `find` з використанням `$or`. Знайдіть істот, які мають колір (`"attributes.color"`) `"Black"` **або** небезпеку (`danger_level`) меншу за `2` (`$lt`).
- **Варіант 2:** напишіть запит `updateOne`. Знайдіть істоту Бакобика (`name: "Buckbeak"`) і змініть його статус на `"Under Observation"`. Після цього виведіть його запис через `find`.
- **Варіант 3:** напишіть запит `find`. Знайдіть усіх істот, у яких кількість зустрічей (`sightings`) знаходиться в діапазоні від `10` до `20` включно (аналог `BETWEEN`). Використайте оператори `$gte` та `$lte` одночасно.
