# Ласкаво просимо до Гоґвортсу!

Цей репозиторій містить усе необхідне для виконання завдань.

## Що в цьому репозиторії?

* **Середовище Codespaces:** Повністю налаштоване середовище для розробки, яке працює у вашому браузері.
* **Інструменти:** Вже встановлено **Rust**, **SQLite** та **NASM**.
* **База даних:** Файл `hogwarts.db` створюється автоматично. Він містить таблиці для Лабораторної роботи №8.

## Як почати?

1.  Натисніть зелену кнопку **`< > Code`** вгорі сторінки.
2.  Перейдіть на вкладку **"Codespaces"**.
3.  Натисніть **"Create codespace on main"**, щоб запустити ваше робоче середовище.

## Лабораторна робота № 8 🌌

**Тема:** Таємниці Астрономічної Вежі: Аналіз Зоряного Пилу.

### Ідея 💡

Студенти виступають у ролі помічників професорки Аврори Сіністри. Наближається великий парад планет, і протягом семестру учні різних факультетів занотували десятки астрономічних спостережень у магічний журнал. Даних стало настільки багато, що знайти закономірності "вручну" просто неможливо!

### Мета

- Опанувати оператор `GROUP BY` для групування даних та підрахунку агрегатів.
- Навчитися використовувати `HAVING` для фільтрації результатів після групування.
- Поєднувати `JOIN`, `GROUP BY` та `HAVING` для складних аналітичних запитів.
- Знайти найактивніші факультети, найпопулярніші сузір'я та справжні астрономічні відкриття серед "зоряного пилу".

### Таблиці бази даних

| Таблиця | Опис |
|---------|------|
| `houses` | Факультети Гоґвортсу (Gryffindor, Slytherin, Ravenclaw, Hufflepuff) |
| `wizards` | Учні та їхня приналежність до факультету |
| `observations` | Журнал астрономічних спостережень з Астрономічної Вежі |

#### Таблиця `observations`

| Колонка | Тип | Опис |
|---------|-----|------|
| `id` | INTEGER | Первинний ключ |
| `wizard_id` | INTEGER | Посилання на учня |
| `body_type` | TEXT | Тип об'єкта: Planet, Star, Comet, Nebula, Galaxy |
| `constellation` | TEXT | Сузір'я спостереження |
| `brightness` | REAL | Яскравість (0–10) |
| `duration_minutes` | INTEGER | Тривалість спостереження (хвилини) |
